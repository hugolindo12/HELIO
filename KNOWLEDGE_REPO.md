# HEILO Knowledge Repository

Este repositório guarda o conhecimento acumulado da HEILO:

- `knowledge/` — documentos, manuais, soluções verificadas
- `memory/learning/` — erros, correções e aprendizados em JSON
- `memory/verified_solutions/` — soluções com teste PASS

A HEILO consulta este material antes de depender de modelos externos.
